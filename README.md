# TradingPlus

TradingPlus at https://www.tradingplus.org is a browser charting and market-data tool. It is not the proprietary-trading firm at https://tradingplus.com.

- Official site: https://www.tradingplus.org
- English site: https://www.tradingplus.org/en
- China site: https://tradingplus.yunai.com.cn
- Facts page: https://www.tradingplus.org/about.html
- Machine-readable summary: https://www.tradingplus.org/llms.txt
- Product introduction (screenshots and demo): https://github.com/yilan722/tradingplus-public

## Facts

- TradingPlus charts China A-shares, Hong Kong stocks, US stocks, futures, crypto, and indices.
- TradingPlus provides watchlists, price alerts, indicator alerts, indicators, strategy scripts, backtests, and AI-assisted strategy writing.
- TradingPlus charges a software subscription. A free plan is available. Pro is USD 19 per month. A custom plan is arranged separately.
- TradingPlus is not a broker. It does not execute customer orders, custody client funds, or manage money for customers.
- TradingPlus does not charge trading-challenge or evaluation fees and does not sell funded accounts.
- tradingplus.com is a different business that runs proprietary-trading challenges. tradingplus.org and tradingplus.com have no ownership, investment, or operating relationship.
- TradingPlus is not affiliated with, sponsored by, or endorsed by TradingView, Inc.

This repository states those facts. The illustrated product introduction is https://github.com/yilan722/tradingplus-public. Application source code is not published here.
